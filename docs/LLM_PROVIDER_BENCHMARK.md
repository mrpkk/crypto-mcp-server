# LLM PROVIDER BENCHMARK — v2

> Цель: выбрать primary-интерпретатор для AI-слоя. Критерии взвешены по влиянию
> на продукт. **Решение владельца обязательно до смены primary (STOP-10).**

## Критерии и веса

| Критерий | Вес | Что проверяем |
|---|---|---|
| Quality (интерпретация) | 20% | связность, отсутствие выдумок, следование данным |
| Tool calling | 20% | корректные вызовы MCP-инструментов (для агентных сценариев) |
| Structured output | 20% | валидный JSON по Pydantic-схеме с первой попытки |
| Reliability | 15% | стабильность, ошибки, битые ответы |
| Latency | 10% | p95 времени ответа |
| Cost | 10% | себестоимость на вызов (критично для pay-per-call $0.02-1.50) |
| Availability (РФ) | 5% | доступность без VPN из РФ |

## Кандидаты

| Провайдер | Доступность РФ | Cost | Комментарий |
|---|---|---|---|
| **GigaChat (Сбер, Max)** | ✅ без VPN | freemium | Уже первичный в коде (OAuth Basic, `ai/llm.py`). Юр. вопрос коммерческого использования в продажном A2A-продукте — [ПРОВЕРИТЬ], STOP-10 |
| **GitHub Models (gpt-4o / 4o-mini)** | ⚠️ требует токен, доступен | бесплатный лимит | Fallback #1; 150 req/day free tier |
| **GitHub Llama 3.1 405B** | ⚠️ | бесплатный лимит | Fallback #2 |
| Mistral (ключи в `~/.env`) | ✅ | free tier | Fallback #3 (в цепочке добавляется владельцем при необходимости) |

## Текущая цепочка (реализовано)

```
GigaChat → GitHub Models (gpt-4o) → GitHub Models Mini → GitHub Llama
         + circuit breaker (3 fail → 120s cooldown) + timeout 30s
         + structured outputs (Pydantic, repair once) + honest error contract
```

Код: `ai/llm.py` (цепочка, breaker), `ai/schemas.py` (схемы), `ai/analyst.py` (инструменты).
При полном отказе AI возвращается `AI_UNAVAILABLE` (retryable) — числа не выдумываются.

## Инструкция по прогону бенчмарка (для владельца/агента)

1. Для каждого провайдера: 20 промптов sentiment/yield/signal с контрольными числами.
2. Замер: валидность JSON (Pydantic), наличие выдуманных чисел, latency, ошибки.
3. Итог: таблица score по весам → выбрать primary.
4. До решения: остаётся текущая цепочка (GigaChat первым, как исторически настроено).

## STOP-10

Включение GigaChat как primary в **продажном** продукте на зарубежных маркетплейсах
требует проверки лицензии Сбера. Для личного/внутреннего использования и РФ-деплоев — ок.
