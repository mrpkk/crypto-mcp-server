# RTM — crypto-mcp-server
> RTM создан 21.08.2026. Статусы: ✅/🟡/❌. Единственный проект с LICENSE (MIT) — эталон open-source упаковки.

## 1. Продуктовая цель
| Поле | Значение |
|---|---|
| Vision | MCP-сервер «крипто-суперсилы» для Claude/Cursor: 14 тулзов — цены, доходности, TA, киты, газ, сигналы |
| Целевой пользователь | Пользователи AI-редакторов и агентных фреймворков |
| Монетизация | Open-source лидогенерация; платные интеграции и деплой под ключ (@mrpkk) |

## 4. Разрывы до коммерческого продукта
1. Нет автоматических тестов — риск молчаливой поломки при смене API бирж.
2. Не зафиксированы контракты ответов тулзов (schema) — ломает интеграторов.
3. Дисклеймеры по торговым сигналам отсутствуют.
